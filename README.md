One satirical sentence roasting lawmakers who would regulate AI, crypto or
the internet but cannot convert a file to PDF — an entry for the
[make.fun competition](https://make.fun/bounty/u-swift-raven-16-the-long-roast-lawmakers-and-the-f3a3bdf7).

> He chairs the committee writing the rules for artificial intelligence and still forwards Word files to his staff with the subject line 'please make PDF'.

`main.ts` (Node 22, standard library only) writes that single sentence to
`/output/entry.txt` — no trailing newline, 153 Unicode code points, inside the
competition's 1–320 character limit. Run it with `node main.ts`; it is
deterministic and writes the same bytes on every run.
